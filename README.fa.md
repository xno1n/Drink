# PULSE (پالس)

شبکهٔ اجتماعی شبیه X با پشتیبانی کامل فارسی (راست‌به‌چپ) و انگلیسی؛ ساخته‌شده با **Next.js 15 و Supabase**.

[English README](README.md)

> **وضعیت:** نسخهٔ اولیه. کد و تست‌ها بدون اجرای کامل CI در محیط نویسنده نوشته شده‌اند. دستورهای بخش «بررسی» را روی سیستم خودتان اجرا کنید و خطاهای اول را فهرست کارهای واقعی بدانید. در این فایل هیچ نتیجهٔ تستی ادعا نشده است.

## امکانات

- ثبت‌نام/ورود، تأیید ایمیل، بازیابی رمز، ورود با OAuth (اختیاری)
- پست (متن، تا ۴ تصویر با متن جایگزین، یا یک ویدیو تا ۲۵ مگابایت)، پاسخ، نقل‌قول، ویرایش، پین، هشتگ و منشن
- فید «برای شما» (امتیازدهی شفاف و قابل‌تنظیم)، «دنبال‌شده‌ها» و «جدیدترین»
- دنبال کردن، درخواست دنبال‌کردن برای حساب خصوصی، بلاک، میوت و **دوستان نزدیک**
- جستجو و اکتشاف، هشتگ‌های پرطرفدار، پیشنهاد حساب
- اعلان‌ها (لحظه‌ای با Realtime)، پیام مستقیم (۱ به ۱، بدون رمزنگاری سرتاسری)
- پروفایل، تنظیمات حریم خصوصی، خروجی گرفتن از داده‌ها، حذف حساب
- پنل مدیریت: گزارش‌ها، تعلیق/بازگردانی کاربر، نقش‌ها، اعتراض‌ها، لاگ ممیزی، تنظیمات سایت
- تم تیره/روشن و طراحی شیشه‌ای

## راه‌اندازی سریع (Supabase Cloud، بدون Docker)

پیش‌نیاز: Node.js نسخهٔ ۲۰ به بالا و یک پروژهٔ Supabase.

```bash
npm install
copy .env.example .env.local      # در لینوکس/مک: cp
# در .env.local آدرس پروژه و کلید anon را بگذارید (Dashboard → Project Settings → API)

npx supabase login
npx supabase link --project-ref <شناسه-پروژه>
npx supabase db push

npm run doctor
npm run dev                       # http://localhost:3000
```

> فقط کلید **anon** را استفاده کنید؛ کلید `service_role` را هرگز در پروژه یا گیت قرار ندهید.

راهنمای قدم‌به‌قدم: [`docs/CLOUD-SETUP.fa.md`](docs/CLOUD-SETUP.fa.md)

حساب‌های دمو (فقط توسعه): فایل `supabase/seed.sql` سه کاربر `alice@demo.local`، `bob@demo.local` و `admin@demo.local` با رمز `demo-password-123` می‌سازد. فقط روی پروژهٔ آزمایشی اجرا کنید، **هرگز روی پروژهٔ واقعی**.

## بررسی

```bash
npm run check:static
npm run typecheck
npm run lint
npm run test:unit     # بدون نیاز به دیتابیس
npm test              # تست‌های یکپارچه: نیاز به .env.local، migrationها و seed روی پروژهٔ آزمایشی
npm run build
```

## ادمین اول

نقش‌های بالاتر از `admin` فقط با SQL داده می‌شوند (SQL Editor):

```sql
update profiles set role = 'super_admin' where username = 'نام_کاربری_شما';
```

## محدودیت‌های شناخته‌شده

- «دوستان نزدیک» سیاست مرکزی `posts_read` را تغییر می‌دهد؛ قبل از استفاده برای محتوای خصوصی واقعی، migration شمارهٔ ۰۰۱۵ و `tests/close-friends.test.ts` را بررسی و اجرا کنید.
- پیام‌های مستقیم فقط ۱ به ۱ هستند و رمزنگاری سرتاسری ندارند.
- فلگ‌های ویژگی مرز امنیتی نیستند؛ امنیت واقعی با RLS دیتابیس است.
- گروه‌های سفارشی، تبدیل ویدیو و Redis پیاده‌سازی نشده‌اند.
